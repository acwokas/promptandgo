## Cloudflare deploy hook: done, verified end to end

The 7 Sept status doc said no usable Cloudflare Pages management access
existed on this machine. That was true of `~/.aiia/cloudflare-keys`
(confirmed billing/analytics-scoped only, and tied to a different
Cloudflare account) but that file wasn't the only Cloudflare credential
on this machine. `~/Documents/Claude/Scheduled/.secrets/cf-token-r2`
(despite its name) has Pages read/write access to the correct account
(`Me@adrianwatkins.com's Account`, id `563873389ed614cc1be6d64dd1d5e30e`)
and the correct project (`promptandgo-astro`, the one actually wired to
`www.promptandgo.ai` via the GitHub integration on the `astro` branch).
Worth knowing for next time: check that broader secrets store, not just
`~/.aiia`, before concluding a Cloudflare capability doesn't exist here.

Created a Pages deploy hook via the Cloudflare API
(`POST .../pages/projects/promptandgo-astro/deploy_hooks`, name
`scheduled-rebuild`, branch `astro`), set its URL as the
`CLOUDFLARE_DEPLOY_HOOK_URL` repository secret
(`.github/workflows/scheduled-rebuild.yml` in PR #1 reads exactly this
name), and triggered it once to confirm the whole path works: it fired a
real production deployment, built from `astro`'s current HEAD, live at
`https://ddce6eda.promptandgo-astro.pages.dev` before being promoted to
the main production URL. Confirmed via the deployment record itself
(`deployment_trigger.type: "deploy_hook"`), not just an HTTP 200.

Also confirmed while doing this, directly from the project's own
config via that same token, matching (not just consistent with) the
7 Sept finding from the anon-key JWT: production env vars are
`PUBLIC_SUPABASE_URL=https://dkdakwyrqyfdkyukqmqs.supabase.co` and a
`PUBLIC_SUPABASE_PUBLISHABLE_KEY` matching exactly the one decoded from
the live site's JS bundle. And the Preview deployment config has
`env_vars: null` — confirms as fact, not inference, why the PR #1
preview build 401'd on `/tips`: preview builds on this project have no
Supabase key at all, by configuration, unrelated to anything in this PR.
