# Glossary factual review, 28 September 2026

Scope: nine definitions on the production Astro glossary. This is a source-backed editorial review, not a claim of whole-site independent verification.

The earlier copy overstated the general benefit of written chain-of-thought prompting, presented fine-tuning as usually unnecessary without evidence, oversimplified token counts and treated retrieval as if an answer necessarily came from supplied data. The update narrows these claims and links the original technical documentation. The Japanese definition now attributes the five-category classification to the Agency for Cultural Affairs.

The production astro branch contains no autonomous factual publication barrier. An older content-pipeline branch has an optional source-text numeric check, but that code is not part of production. No new factual approval is implied by the glossary links alone. A complete gate needs final-content evidence validation and deployment-bound approval, including database-derived tips.
